# RankProbe 0.1.0a4

First complete GitHub distribution / 首个完整 GitHub 发行包。

RankProbe checks exported recommendation and retrieval scores for ties, repeated
candidates, changed query/candidate pools, conflicting judgments and metric
coverage. It produces offline HTML and JSON reports. The core uses the Python
standard library and needs no model, API key or cloud account.

## Download and run / 下载使用

Choose **`RankProbe-0.1.0a4.zip`** under Assets for the complete offline bundle.
It contains the wheel, source, original example fixtures, English/Chinese
instructions, MIT license and per-file manifest. Extract the entire ZIP and open
`START_HERE.md`. Python 3.10+ is required; the bundled wheel installs without
network access or additional runtime packages.

优先下载 **`RankProbe-0.1.0a4.zip`**，完整解压后打开 `START_HERE.md`。
其中包含可离线安装的包、源码、示例和中英说明。无需现成实验即可运行 demo。

Separate wheel and source distributions are also attached. `SHA256SUMS` verifies
all attached assets except itself; `RELEASE_INFO.json` records the public source
commit and CI link. The automatic repository Source code ZIP includes the
separate original coursework; the curated RankProbe ZIP contains RankProbe only.

## Included and bounded / 范围

- CSV/JSONL and ordinary TREC run/qrels input; local CLI and Python API.
- Known-prefix MRR, declared NDCG and conditional Recall with eligible-query
  counts, reference pools and explicit unknown-label/completeness assumptions.
- Tie sensitivity, duplicates, conflicts and run comparability diagnostics.
- English/Chinese comparison guidance and actionable source-specific recipes.
- Optional, bounded BEIR/MTEB/ReChorus/RecBole source-checkout integration recipes.
- Fixed public-input reference checks and a controlled retained-score recovery
  case. Raw third-party datasets, user predictions and private trial records are
  excluded from the curated release.

This is an **alpha prerelease**, with its complete engineering first-version
scope distributed for community use. Missing judgments stay unknown. Findings
are evidence to inspect, not certification of leakage avoidance or model quality.
Independent adoption, measured human time saved and general framework parity are
not established. PyPI and cloud hosting are not part of this release.

The linked CI covers Windows/Ubuntu Python 3.10, 3.12 and 3.13 and separate 3.15
core build/install checks, plus fixed framework/reference jobs. Python 3.14 and
full optional frameworks on 3.15 are not covered by this matrix.

Report reproducible bugs through the repository's Issues, prefixed `[RankProbe]`.
Include the version, OS/Python, command and a minimal original synthetic input.
Do not attach credentials, private predictions or licensed raw datasets.
